# Portfolio — quick start

This is a Quarto website project matching the structure recommended in the Department of
Statistical Sciences portfolio guidelines (UCT, July 2026).

## To use it

1. Rename the folder if you like, then open it in RStudio / VS Code / your terminal.
2. Fill in `[Your Name]`, `[XXXXXXXX]` and the course code in `index.qmd`.
3. For each of your four substantial projects, duplicate `projects/project-01/` (e.g. to
   `projects/project-02/`), fill in `index.qmd` (one-page summary) and `detailed-analysis.qmd`,
   and add a row + link in `projects/index.qmd`.
4. Add a new file under `journal/entries/` for each journal entry (copy
   `2026-01-01-entry-template.qmd`), and link it from `journal/index.qmd`.
5. Fill in `section-1/section-1.qmd` and `section-2/section-2.qmd` as you go through each
   teaching session.
6. Keep `ai-use-log.qmd` updated with substantive AI use.
7. Write `reflective-commentary.qmd` (1000–2000 words) nearer the end, but draft it
   incrementally.
8. Render early and often: `quarto render` (or `quarto preview` while working).
9. Submit both the rendered site (`_site/`) and this source folder (zipped, or as a repo link).

## Submission checklist (from the department guidelines)

- [ ] Four substantial projects, each with a one-page summary and a link to the detailed analysis
- [ ] At least one project involving model comparison
- [ ] At least one project involving computational / statistical programming
- [ ] At least one project involving real-world data
- [ ] Smaller pieces of work for sections without a major project
- [ ] Reflective commentary (1000–2000 words)
- [ ] A journal that is up to date and linked from the landing page
- [ ] Worked tutorials, an implementation, and an overview for every section
- [ ] Code, data, and computational notebooks linked, or included in an appendix
- [ ] An AI use log with links to prompts and conversations
- [ ] A clear structure, with working links and easy navigation
- [ ] Name and student number stated clearly on the landing page
- [ ] Portfolio rendered successfully well before the deadline, and backed up
- [ ] Both the rendered output and the source files included in your submission
